# CollabFlow

CollabFlow is a real-time team project management platform built as a full-stack learning project.

## Current Technology

### Frontend
- React.js
- Vite

### Backend
- Node.js
- Express.js

### Planned Database
- MySQL

## Current Project Structure

- client - React frontend
- server - Node.js and Express backend
- database - Database scripts will be added in Phase 2
- docs - Project documentation

## Current Progress

Phase 1 - Foundation and Project Setup

Frontend and backend communication is working successfully.
